
# User stories 

User stories the applications should solve


## Visitor wants to see all "freiwillige Wohnadresse" from persons of certain type
- Desc: Visitor wants see only those points that represent "voluntary_residence" for to the victim type "jewish" 
- Acceptance: Some kind of filter possible that allows this kind of selection

## School teacher wants to use it in teaching
- Desc: A school teacher wants to show that most victims in graz were being forced to live in certain regions. He wants
to show patterns of prosecution to students.
- Acceptance: Sized markers / circles representing the count of people being forced to live e.g. in vienna - as opposed to
smaller circles to live somewhere else

## Anonymous visitor wants to see prosecution history of a relative
- Desc: An anonymous visitor wants to understand the steps the prosecution of a relative.
- Acceptance: Points connected through round lines showing the start and end of the events (from "voluntary_residence" to "death")
